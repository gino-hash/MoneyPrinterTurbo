# Codex 후속 보강 지점

이 파일은 Claude Code가 1차 MVP 골격을 만든 뒤, Codex에게 넘겨 세부 보강할 때 쓰는 메모입니다.

## Codex에게 맡기기 좋은 작업
1. draft 생성 로직 리팩토링
2. JSON 스키마 정리 및 validation 추가
3. DB 계층 정리
4. 에러 처리 보강
5. 복사 버튼/상태 저장 UX 개선
6. 테스트 스크립트 추가
7. 업종 템플릿 2~3개 확장
8. 금지어/필수어 반영 로직 보강

## Codex 요청 예시
- 현재 Claude가 만든 MVP를 읽고 구조를 깨지 않는 범위에서 리팩토링하라.
- 출력 JSON 스키마를 엄격하게 정리하라.
- draft 생성 결과에 필수 필드 누락이 없도록 validation을 추가하라.
- 저장/조회/상태변경 흐름에 대한 간단한 테스트를 추가하라.

## 주의
Codex는 새 기획을 다시 짜기보다,
**기존 Claude 골격을 보강하는 역할**로 쓰는 것이 좋습니다.
