# 업종 맞춤형 쇼츠 자동제작 시스템 — Claude Code 통합 브리프

## 1. 서비스 목표 / 문제 정의
이 프로젝트의 목표는 **업종별 원본 자료를 입력하면, 해당 업종 문맥에 맞는 쇼츠 콘텐츠 패키지를 반자동으로 생성하는 웹앱 MVP**를 만드는 것입니다.

핵심은 단순 영상 생성기가 아닙니다.
이 도구는 다음을 시스템화해야 합니다.
- 어떤 소재로 쇼츠를 만들지
- 어떤 후킹 구조가 맞는지
- 어떤 톤과 CTA가 맞는지
- 어떤 장면 구성으로 영상 생성 툴에 넘길지

즉, 이 제품은 `AI 영상 툴 프롬프트 생성기`가 아니라,
**업종 맞춤형 쇼츠 기획 + 카피 + 제작 패키지 생성 시스템**입니다.

---

## 2. 운영 철학
1. 처음부터 만능 생성기로 가지 않는다.
2. **업종 1개용 vertical MVP**로 시작한다.
3. 조회수보다 **문의/상담/제안 전환형 콘텐츠**를 우선한다.
4. 낮의 영상 복제 구조는 금지한다.
5. 자동 업로드보다 **사람 검수 후 배포**를 기본값으로 둔다.
6. 영상 생성 자체보다 `후킹 구조 / CTA / 업종 문맥화 / 반복 운영 효율화`를 더 중요한 가치로 본다.

---

## 3. 이번 구현 범위(MVP)
Claude는 이번 1차 구현에서 아래까지만 완성하면 됩니다.

### MVP 입력
- 프로젝트명
- 업종 선택(초기엔 1개 업종만 지원해도 됨)
- 타깃 고객
- 목표 CTA
- 톤
- 원본 텍스트 입력
- 원본 이미지 경로 또는 메모 필드
- 금지어 / 필수어

### MVP 출력
초안 3세트 생성:
- angle
- hook
- script
- scene_plan
- video_prompt
- title
- thumbnail_copy
- description
- pinned_comment
- cta

### MVP 기능
- 입력 저장
- 업종 템플릿 로드
- 초안 3세트 생성
- 초안 상세보기
- 승인/수정 상태 저장
- 생성 이력 보기

### 이번 버전에서 하지 말 것
- 완전 자동 영상 렌더링
- 완전 자동 업로드
- 외부 SNS API 배포
- 광고 집행 자동화
- 성과 분석 대시보드 고도화
- 멀티유저/복잡한 권한 시스템

## 4. 첫 타깃 업종 기본값
기본 예시는 아래 중 하나로 잡되, 구조는 업종 확장 가능하게 만들어 주세요.

### 권장 기본값
- `b2b-service`
- 또는 `solar-maintenance`
- 또는 `education-coaching`

우선 구현 편의상 **한 업종만 하드코딩 또는 JSON 템플릿 1개**로 시작해도 괜찮습니다.
하지만 구조는 나중에 업종 템플릿 추가가 쉬워야 합니다.

---

## 5. 기술 방향
### 권장 스택
가볍고 빠르게:
- Frontend: 단순 HTML/JS 또는 React/Vite 중 Claude가 빠르게 만들 수 있는 것
- Backend: Node.js
- Storage: SQLite 또는 파일 기반 JSON 저장

### 이유
이 MVP는 SaaS 스케일보다 **빠른 내부 실험**이 먼저이므로,
무거운 인프라보다 빠른 반복이 중요합니다.

## 6. 시스템 구조 요구사항
### 모듈 1. Input Collector
수집 필드:
- project_name
- industry
- target_audience
- goal_cta
- tone
- source_text
- source_notes
- source_images[]
- banned_phrases[]
- required_phrases[]

### 모듈 2. Template Loader
업종별 템플릿을 불러옵니다.
예시 템플릿 항목:
- pain_points
- desired_outcomes
- hook_patterns
- cta_patterns
- banned_claims
- required_disclaimers
- preferred_video_styles

### 모듈 3. Draft Generator
입력 + 템플릿을 조합해 초안 3세트를 만듭니다.
각 초안은 서로 다른 angle을 가져야 합니다.
예:
- 문제제기형
- 전후비교형
- 실수방지형

### 모듈 4. Review Panel
각 초안을 카드 형태로 보여주고,
- 승인
- 수정중
- 보류
상태를 저장합니다.

### 모듈 5. History Store
생성 이력과 수정 이력을 간단히 남깁니다.

## 8. 출력 품질 규칙
Claude는 생성 로직 또는 기본 템플릿에서 아래 품질 규칙을 반영해야 합니다.

1. **과장 금지**
   - “무조건”, “100%”, “누구나 쉽게 큰돈” 같은 표현은 피하기
2. **업종 문맥 반영**
   - 아무 업종에나 같은 훅을 쓰지 않기
3. **CTA 정합성**
   - 목표 CTA가 상담문의면 결과물도 상담문의형이어야 함
4. **복붙 가능성**
   - 출력은 사람이 바로 옮겨 쓸 수 있게 텍스트 중심
5. **원본 기반성**
   - source_text와 무관한 뜬구름 메시지 낮발 금지

## 12. 검증 기준(Exit Criteria)
아래가 되면 1차 완료로 봅니다.

1. 새 프로젝트를 생성할 수 있다.
2. source_text를 넣고 저장할 수 있다.
3. 업종 템플릿 1개를 불러올 수 있다.
4. 초안 3세트가 생성된다.
5. 각 초안에 필수 필드가 모두 있다.
6. 승인/보류 상태를 저장할 수 있다.
7. 이전 프로젝트/생성 이력을 다시 볼 수 있다.

---

## 13. 구현 시 절대 놓치지 말 것
- 이건 영상 생성 툴 자체를 만드는 프로젝트가 아니다.
- 핵심은 **업종 문맥화된 쇼츠 기획 패키지**다.
- 자동화는 “생산 보조”이며, 사람 검수는 필수다.
- 첫 버전은 작아야 한다.
- 구조만 좋으면 이후에 업종/툴 연결은 쉽게 확장할 수 있어야 한다.
