# 업종 맞춤형 쇼츠 자동제작 시스템 — 핸드오프 패키지

이 폴더는 **Claude Code가 바로 구현을 시작할 수 있도록 정리한 실행 패키지**입니다.

## 이 패키지의 목표
`업종별 원본 자료를 넣으면 쇼츠 아이디어 → 후킹 → 대본 → 썸네일 문구 → 영상 생성 프롬프트 → 업로드 문구 → CTA`까지 묶어서 출력하는 **반자동 쇼츠 제작 시스템 MVP**를 만드는 것입니다.

## Claude가 읽는 순서
1. `01_통합브리프_업종맞춤_쇼츠_자동제작시스템.md`
2. `02_빠른실행프롬프트_ClaudeCode용.md`
3. `03_출력예시_JSON스키마.md`

## 작업 루트 가정
- **권장 작업 루트:** 새 별도 프로젝트 폴더
- Claude Code 시작 시 예시 작업 폴더:
  - Windows: `C:\Users\user\projects\shorts-workbench`
  - 또는 Claude가 현재 생성 가능한 새 작업 폴더
- 이 패키지의 상대경로 지시는 **프로젝트 루트 기준**입니다.

## 이번 버전의 중요한 방향
- 처음부터 만능 생성기로 가지 않음
- **업종 1개용 MVP**부터 시작
- 완전 자동 업로드보다 **사람 검수 후 배포**를 기본값으로 둠
- 조회수보다 **문의/상담/제안 전환형 결과물**을 우선함
- 남의 영상 복제 구조 금지, **권리 명확한 원본 기반**만 사용

## 구현 우선순위
1. 입력 폼
2. 업종 템플릿 로더
3. 초안 3세트 생성 파이프라인
4. 결과 패키지 화면
5. 승인/수정 저장

## 포함 파일
- `01_통합브리프_업종맞춤_쇼츠_자동제작시스템.md` — 제품 목표, 구조, 데이터모델, MVP 범위, 구현 요구사항 전체
- `02_빠른실행프롬프트_ClaudeCode용.md` — Claude Code에 바로 붙여넣는 짧은 실행 프롬프트
- `03_출력예시_JSON스키마.md` — 결과 포맷 예시
- `04_Codex_후속보강지점.md` — Claude 1차 구현 후 Codex에게 맡길 세부 보강 포인트

## 핵심 주의사항
- 이 프로젝트는 **쇼핑쇼츠 부업 복제기**가 아님
- 목표는 `업종 맞춤형 쇼츠 생산 시스템`
- 진짜 가치는 영상 생성 그 자체보다 후킹 구조 / CTA 설계 / 업종별 문맥화 / 반복 운영 효율화에 있음

## 기대 산출물
MVP 완성 시 아래가 가능해야 합니다.
- 원본 입력 1건
- 업종 선택 1개
- 목표 CTA 선택 1개
- 결과 초안 3세트 생성
- 각 세트에 hook / script / scene_plan / video_prompt / title / thumbnail_copy / description / pinned_comment 포함

## 한 줄 요약
Claude는 이 패키지를 읽고 **새 프로젝트 기준으로 업종 1개용 쇼츠 워크벤치 MVP를 바로 구현**하면 됩니다.
